# Research-of-cybersecurity
Framework for Simulation and Statistical Processing of Physical-Tap Detection in Optical Fiber Using Sagnac Interferometry.
This repository relates path perturbations on the order of nanometers to phase shifts via time delays and employs statistical filtering techniques (Sliding Window Z-Score and CUSUM) in order to detect physical-layer attacks and filter out noise from the environment.
Sagnac Interferometer Modeling: Simulates counter-propagating clockwise (CW) and counter-clockwise (CCW) optical paths and phase shifts
Environmental Noise Engine: Incorporates Gaussian phase noise and low-frequency thermal drift
Statistical Intrusion Detection: Features sliding-window Z-score calculations alongside Cumulative Sum (CUSUM) filtering for low-latency anomaly detection
Performance Analysis: Calculates real-time detection delays, alarm triggers, and ROC curves
Adversarial Tap Simulation: Models localized asymmetric path length changes with exponential onset dynamics
